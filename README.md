# Задание 1. Заполнение двумерных массивов

### Текст задачи

Первый массив, размерностью n x m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по столбцам от первых элементов столбца к последним.
Второй массив, размерностью n x n, заполняется случайными числами так, что нечетные числа записаны в элементы матрицы, которые на шахматной доске были бы черными, а четные числа записываются в элементы, которые на шахматной доске были бы белыми.
Третий массив, размерностью n x n, заполняется для произвольного n так же, как для n=5 (спираль от правого нижнего угла).

### Алгоритм решения

1. Создан класс `Matrix` с единственным полем `_data` (двумерный массив).
2. Для трех массивов реализованы разные конструкторы:
   - Первый: чтение с клавиатуры в цикле по столбцам.
   - Второй: проверка `(i + j) % 2 == 0` для определения «цвета» клетки, генерация четных/нечетных чисел.
   - Третий: обход по диагоналям с чередованием направления (спираль).
3. Для удобства выбора типа заполнения создано перечисление `MatrixType`.

# Задание 3. Матричное выражение

### Текст задачи

A^T * C^T + B * C

### Алгоритм решения

1. В классе `Matrix` перегружены операторы `+` и `*`.
2. Реализован метод `Transpose()` для транспонирования матрицы.
3. Выражение вычисляется последовательно: сначала `A.Transpose() * C.Transpose()`, затем `B * C`, и результаты складываются.

# Задание 4. Бинарные файлы

### Текст задачи

Найти количество удвоенных нечетных чисел среди компонент файла.

### Алгоритм решения

1. Файл заполняется случайными числами через `BinaryWriter`.
2. Чтение происходит через `BinaryReader` в цикле `while` до конца файла.
3. Число считается «удвоенным нечетным», если оно четное, но при делении на 2 дает нечетное (`num % 2 == 0 && (num / 2) % 2 != 0`).

# Задание 8. Текстовые файлы (строки)

Создать новый текстовый файл, каждая строка которого содержит последний символ соответствующей строки исходного файла.

### Алгоритм решения

1. Исходный файл заполняется произвольным текстом.
